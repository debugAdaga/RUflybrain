ИИ Мозг мухи
Руководство по взаимодействию
Кормить — кликните по холсту, чтобы положить еду.
Прикоснуться — кликните по мухе, чтобы прикоснуться.
Ветер — зажмите и тяните рядом с мухой.
Свет — переключает Ярко / Тускло / Темно.
Температура — Нейтрально / Тепло / Холодно.
🐝 Добавить муху — создаёт копию мухи.
❤️ Размножить — создаёт потомка между двумя мухами.
🕵️ Отчёт — выводит в консоль список сущностей и их движение.
